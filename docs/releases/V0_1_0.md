# THE EYES 0.1.0 — The First Observance

First playable local 3D prototype of Darknigthmare's original asymmetrical nightmare game.

## Download and play

Download **THE_EYES_v0.1.0_Windows_x64.zip**, extract the complete archive, and open **THE_EYES.exe**. Keep the supplied files together. The Godot editor is not required to play this package.

The archive includes English and French quick starts, engine/font notices, build metadata and file checksums. The separate **SHA256SUMS.txt** verifies the downloadable ZIP. Start with **Story** difficulty to learn the chamber.

## Playable in this version

- **Survivor versus an AI Eye**, or **human Eye versus four physical AI survivors**.
- One connected 3D observatory with real collisions, cover, four fixed Eye sockets and an escape corridor.
- Three complete trials: **The Silent Countdown**, **Trial of the Echoes**, and **Clockwork Relay**.
- Four survivor archetypes: **Veil, Tinker, Runner and Keeper**, with distinct abilities.
- Eye energy/cooldowns, collision-based line of sight, marking, eight floor traps and a two-shadow limit.
- Three difficulties, seeded Echo sequence, a recovery challenge, an in-game manual, map, settings and match results.

Complete the three seals, then hold the escape interaction at the open doorway before the countdown ends. The first survivor to escape wins for the survivor team. The Eye wins by stopping every escape through elimination or the clock.

## Controls

| Role | Controls |
| --- | --- |
| Survivor | WASD / physical ZQSD positions or arrows; mouse to look; Shift to sprint; Ctrl/C to crouch; Space to jump |
| Interaction | E / hold E; Q for archetype ability; 1–4 for Echo symbols; R to replay its sequence |
| Eye | Mouse to aim; 1–4 or wheel to switch sockets; left click for a trap; right click to mark; Q to summon |
| Shared | Tab for the map; Escape for pause/settings or closing a trial panel |

## Prototype limits

This is an **unsigned development prerelease**. The game was tested with the native Linux Godot runtime; the Windows executable was exported and structurally verified, but **has not been executed on a native Windows machine**. Automated completion establishes a connected playable route, not a novice usability study or difficulty-balance certification. No hardware FPS benchmark is claimed.

The prototype is **local only**. Internet multiplayer, matchmaking, controller/remapping coverage, production character rigs/animation, progression and the other **22 trials** remain future work. The included UE5 project is a **Blueprint-only construction foundation**, with no compiled Unreal gameplay assets or completed Unreal build.

The repository also contains the [English game bible covering all 25 trials](https://github.com/darknigthmare/THE_EYES/tree/6c817877f1e66365655e0245a45570f7484680c8/docs/bible), the source brief, art/audio production specifications, and detailed UE5 networking and Blueprint implementation plans.
