# THE EYES 0.5.0 — The Trial Workshop

Release date: 26 November 2026. Local Windows x64 development prerelease.
Godot 4.7.2 prototype; UE5 remains the Blueprint-only production target.

## Learn one trial, then return to the observance

The new **Trial Workshop** offers each of the nine implemented objectives as
an individual exercise. Choose a trial, one of the four survivor archetypes and
a seed. Start in the observatory, walk to the actual devices and complete the
same objective through its real interactions. Only one bay is active.

Practice removes the Eye AI, gaze damage, hostile traps/shadows, match deadline
and escape requirement. Cargo, line of sight, reach, cooldowns, continuous holds,
checkpoint loss and puzzle generation retain their ordinary rules. A practice
completion awards its single seal and a dedicated completion event; it never
creates a competitive victory or replaces the last-match ledger.

The catalogue explains the controls and checkpoints. A contextual guide follows
public progress without revealing unseen puzzle answers. The result screen
provides **same-seed retry, another seed, next trial, catalogue and main menu**.

## A separate local notebook

The notebook stores attempts, completions and best times separately for every
trial and survivor archetype: at most 9 × 4 records. Tinker's machinery advantage
is therefore compared only with another Tinker attempt. It is a local record,
not a leaderboard or saved in-progress match.

Files now use the stable `THE_EYES` user-data directory. New writes use a staged
file and a single previous `.bak`; failed replacement can restore that copy.
An absent primary may load the backup, while corrupt or future-version files
are preserved. A visible **SESSION ONLY / NOTEBOOK NOT SAVED** message appears
in the catalogue or result when persistence is unavailable. Old version-named
data folders remain intact and are not automatically imported.

## Manual and interruption handling

- **F1** opens the field manual from gameplay and pause, as well as the menus.
- Closing a manual opened during play returns to the pause screen. Resume is explicit.
- Losing application focus pauses gameplay. Returning focus never resumes it automatically.
- Pause, restart and leaving a session release held gameplay actions and cancel unfinished continuous interactions.
- Echoes keeps its current sequence behind the pause screen; its buttons cannot submit while paused.
- FOV controls explicitly affect survivors and spectators. The Eye stays at 85 degrees to preserve its sight-cone rules.

## Competitive game retained

The three existing match modes remain: human Survivor, human Eye and a local
five-survivor Squad with four AI allies. First, Second, Third and Seeded Mix
retain their nine-trial pool and **27 Mix combinations**. This release adds no
new competitive trial, realm, network lobby or second human controller.

The English bible adds a dedicated Workshop chapter and technical implementation
recipe. Unreal construction material now includes **ten CSV tables**, with
`DT_PracticeDrills.csv` describing the nine exercises. Compiled playable UE5
maps and Blueprint assets remain future work.

## Verification and package

The release gates require **17 gameplay suites** and **21 native Windows
headless startup cases**: the 12 existing mode/contract combinations plus all
nine individual practice selections. Ordinary-input routes cover every drill
separately and retain the complete active-Eye competitive routes.

[The exact verification report](../qa/V0_5_VERIFICATION.md) records measured
counts, retained logs, source identities and platform results. Native screenshots
are deliberately staged presentation fixtures; they are not playthrough proof.
The Windows startup report is a test without graphical rendering and does not
establish interactive hardware compatibility or performance.

Extract the complete ZIP and run `THE_EYES.exe`. The package includes English and
French quickstarts, version/provenance metadata and checksums. Godot Editor is
not required. The executable is an unsigned development build.
